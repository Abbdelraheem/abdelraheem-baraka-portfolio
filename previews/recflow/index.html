Zero-API-Load Architecture

How RecFlow streams massive recording archives without overwhelming node servers.

01

Direct Browser Chunking

MediaRecorder API extracts 5-second WebM fragments on the client thread, bypassing backend memory allocations.

02

Pre-Signed Multi-part S3

The API issues cryptographically signed URLs. Each media chunk uploads directly to Cloudflare R2 / S3 without touching backend bandwidth.

03

BullMQ Worker Stitching

Upon final chunk completion, an asynchronous Redis BullMQ worker concatenates fragments into MP4 and generates HLS streams.
